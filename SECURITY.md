# Security policy

## Reporting a vulnerability

Email innovate@kromatic.com with "Security" in the subject. Include what you
found, how to reproduce it, and which server or file it affects. Please do
not open a public issue for a vulnerability.

We aim to acknowledge reports within three business days.

## Scope

- This repository: listing material only (README, manifests, images). The
  most important thing to report here is a wrong or tampered MCP URL, since
  clients install from these files.
- The servers themselves (`neumann.kromatic.com`, `fermi.kromatic.com`,
  `api.kromatic.com/mcp/krobot`) are run by Kromatic, and reports about them
  go to the same address.

## Supported versions

Only the latest tag and the `main` branch are supported.

## Who handles reports

The Kromatic team, reachable at innovate@kromatic.com, owns this repository
and the three servers. That address is a team inbox, not one person's, so
reports are not lost when someone is away.
